A 陈述式现在时Presente de indicativohablo / como / vivo 不规则：soy, estoy, voy, tengo, hago, séTrabajo en una oficina.↳我在办公室工作。现在的事实、习惯性动作或普遍真理；也可表近期将来（Mañana voy al médico）。
现在完成时Pretérito perfecto de indicativohe / has / ha / hemos / habéis / han + p.p. 例：he hablado, has vistoYa he terminado el informe.↳我已经把报告写完了。到说话这一刻为止已完成，且与现在有关联（今天、本周、刚发生）。与简单过去时的区别在于是否切断与现在的联系。
过去未完成时Pretérito imperfecto de indicativohablaba / comía / vivía 不规则：sabía, iba, veía, tenía, podíaNo sabía que venías.↳我当时不知道你要来。过去的持续状态、背景描写、习惯；不强调起止。saber 的未完成时是 sabía，不是 supo。
简单过去时Pretérito indefinido de indicativohablé / comí / viví 不规则：supe, hice, fui, dije, puse, lleguéAyer supe la noticia.↳我昨天得知了这个消息。过去某个具体时点上完整、一次性的动作。supe 是 saber 的简单过去时，意为“得知”，与 sabía（一直知道/当时不知道）分工不同。
过去完成时Pretérito pluscuamperfecto de indicativohabía / habías / había / habíamos / habíais / habían + p.p.Ya había comido cuando llegaste.↳你来的时候我已经吃过饭了。“过去的过去”：先于另一个过去动作完成；常用于叙述背景，末尾可接 cuando llegaste。
将来未完成时Futuro simple de indicativohablaré / comeré / viviré 不规则：tendré, podré, diré, haré, saldré, vendréMañana iré al aeropuerto.↳我明天去机场。将来会发生的事；也可表推测或让步（Serán las tres. 大概三点了）。日常口语常改用 ir a + 不定式。
将来完成时Futuro compuesto de indicativohabré / habrás / habrá / habremos / habréis / habrán + p.p.Para mañana ya habré terminado.↳到明天我就已经完成了。到将来某一时点之前已经完成；也可表对过去的推测（Habrá llegado ya. 他大概已经到了）。
条件式简单时Condicional simplehablaría / comería / viviría 词根同将来时：tendría, podría, diría, haríaSi tuviera tiempo, iría contigo.↳我要是有时间，就跟你一起去。第二类条件句的结果部分；也用于委婉请求（¿Podrías ayudarme?）和过去将来（Dijo que vendría.）。
条件式复合时Condicional compuestohabría / habrías / habría / habríamos / habríais / habrían + p.p.Habría ido, pero estaba enfermo.↳我本来会去的，但当时病了。第三类条件句的结果部分；表“本会发生却没发生”，也用于对过去的推测（Habría salido ya.）。
B 虚拟式虚拟式现在时Presente de subjuntivo规则：-ar → hable；-er/-ir → coma / viva 不规则：vaya, sea, haya, sepa, dé, esté, pueda, quiera, venga, tenga, haga, diga, pongaEspero que vengas.↳我希望你来。愿望、要求、建议、情感、否定判断、目的、将来时间从句都用它；主句现在时触发。
虚拟式现在完成时Pretérito perfecto de subjuntivohaya / hayas / haya / hayamos / hayáis / hayan + p.p. 例：haya hablado, hayas vistoEspero que hayas terminado.↳我希望你已经完成了。虚拟框架下的“已完成”：到说话时或将来某节点前做完；也用于否定判断中的近期过去（No creo que hayan llegado）。
虚拟式过去未完成时Pretérito imperfecto de subjuntivo规则：hablara / hablase；comiera / comiese；viviera / viviese 不规则：tuviera/tuviese, fuera/fuese, pudiera/pudiese, supiera/supieseSi tuviera tiempo, viajaría más.↳要是我有时间，我会多旅行。第二类条件句；过去主句后的从句；低概率愿望；委婉语气（quisiera）；como si 表与现在相反。
虚拟式过去完成时Pretérito pluscuamperfecto de subjuntivohubiera / hubiese + p.p. 例：hubiera sabido, hubieses venidoSi hubiera sabido, habría venido.↳如果我当时知道，我本会来的。第三类条件句的 si 从句；过去反事实；对过去的遗憾（Ojalá hubiera aceptado）；como si 表与过去相反。
虚拟式将来未完成时Futuro simple de subjuntivohablare, comiere, viviere 不规则：fuere, hiciere, dijere, tuviere, pudiere, viniereSi alguien viniere, avísame.↳若有人来，请告诉我。现代罕用：法律条文、谚语、古旧条件与时间从句。日常一律换成虚拟式现在时（Si alguien viene, avísame. 用陈述式）。
虚拟式将来完成时Futuro compuesto de subjuntivohubiere / hubieres / hubiere / hubiéremos / hubiereis / hubieren + p.p.Si alguien hubiere visto algo sospechoso, que lo comunique a la policía.↳若有人看到可疑情况，请通知警方。现代罕用：法律公文中假设“到那时已经完成”。现代写作 Si alguien ha visto…（si 从句用陈述式）。
C 命令式肯定命令式（tú）Imperativo afirmativo (tú)avisa（= 陈述式第三人称单数） 不规则：di, haz, ve, ven, pon, sal, sé, tenAvisa a tu madre.↳你去告诉你妈妈。tú 的肯定命令式与陈述式第三人称单数同形（él avisa → ¡avisa!）；只有少数不规则需单独记。
肯定命令式（tú）+ 代词 meImperativo afirmativo (tú) + meavisa + me → avísame （重音需标出）Avísame cuando llegues.↳你到了就告诉我。肯定命令式后接 me / te / lo / la 等代词时连写，并在原重音处补写重音符号：avísame ✅，avisame ❌。从句 cuando llegues 仍用虚拟式。
肯定命令式（usted）Imperativo afirmativo (usted)avise（借用虚拟式第三人称单数） 不规则：vaya, sea, sepa, dé, esté, tenga, haga, diga, pongaAvise a la policía.↳请您通知警方。usted 命令式借用虚拟式现在时第三人称单数：avise / coma / viva；ir 为 vaya，ser 为 sea。
肯定命令式（usted）+ 代词 meImperativo afirmativo (usted) + meavise + me → avíseme （重音需标出）Avíseme mañana.↳请您明天通知我。加代词同样连写并加重音：avíseme。否定时代词前置并分开写：No me avise.（请不要通知我）。
虚拟式现在时 = usted / él 命令式Presente de subjuntivo = imperativo (usted / él)comuniqueQue lo comunique a la policía.↳请（您/他）通知警方。独立祈愿句：que + 虚拟式，省去主句 deseo/espero。comunique 一身两职——既是虚拟式现在时，也是 usted 命令式。注意 comuniqué 带重音才是“我通知了”（简单过去时）。
D 条件句第一类：现实可能Condicional tipo 1 · realSi + 陈述式现在时，主句陈述式将来 / 现在 / 命令式Si tengo tiempo, iré.↳如果我有时间，我就去。条件被视为有可能实现。主句也可用现在时（Si tengo tiempo, voy）或命令式（Si tienes tiempo, avísame）。
第二类：现在 / 未来不太现实Condicional tipo 2 · irrealSi + 虚拟式过去未完成时，主句条件式简单时Si tuviera tiempo, iría.↳如果我现在有时间，我就会去（其实没时间）。与现在事实相反或实现可能性很低。si 从句用 tuviera，主句用 iría，两边都不能配现在时。
第三类：过去反事实Condicional tipo 3 · irreal pasadoSi + hubiera / hubiese + p.p.，主句 habría + p.p.Si hubiera sabido, habría venido.↳如果我当时知道，我本会来的（当时不知道，也没来）。与过去事实相反。口语中主句也常说 hubiera venido，书面标准写 habría venido。

B1虚拟式现在时Presente de subjuntivo规则：-ar → hable；-er/-ir → coma / viva 不规则：vaya, sea, haya, sepa, dé, esté, pueda, quiera, venga, tenga, haga, diga, ponga①愿望、请求、建议、命令Espero que vengas pronto.↳我希望你早点来。esperar que 是最典型的虚拟式触发结构；vengas 指尚未发生、只存在于说话人愿望中的动作。若改用陈述式 vendrás，就把“来”当成已确定的事实预告，语气从愿望变成断言。同类动词：querer / pedir / rogar / sugerir / aconsejar / mandar que。
②情感、评价Me alegra que estés aquí.↳我很高兴你在这儿。情感、评价类词语（alegrar, gustar, encantar, molestar, sorprender, es bueno / importante / una pena que…）引导的从句一律用虚拟式，因为从句内容是说话人的主观评价而非客观陈述。estés 是 estar 的虚拟式，描述引发情感的现实状态。
③怀疑、否定判断、可能性No creo que sea verdad.↳我不认为这是真的。creer / pensar / parecer 在否定或疑问时失去“断言”力量，从句改用虚拟式（sea 是 ser）。对比肯定句 Creo que es verdad.（用陈述式）。同类：No es cierto / No estoy seguro de que / Es posible que / Puede que / Quizás。
④目的：para que / a fin de queTe lo digo para que lo sepas.↳我告诉你是为了让你知道。para que / a fin de que 引出的是“目的”，本身即要求虚拟式；又因主句主语是“我”、从句主语是“你”，不能用 para + 不定式（para saberlo 只在同主语时用）。sepas 是 saber 的虚拟式。
⑤时间从句指将来未发生Cuando llegues, avísame.↳你到了就告诉我。cuando 引导的从句指将来、尚未发生且不确定的事件时用虚拟式（llegues 是 llegar）。若指习惯或已发生的事则用陈述式：Cuando llega, siempre avisa.（他每次到都会说一声）。同类连词：en cuanto, mientras, hasta que, antes de que, después de que, tan pronto como。
⑥让步：aunque / por más que（不确定）Aunque llueva, saldremos.↳即使下雨我们也出去。aunque + 虚拟式表示“障碍可能存在、但说话人不确定或不当它是事实”，语气是“哪怕真下”。若已知事实（确实在下雨）则用陈述式 Aunque llueve, saldremos.（虽然在下雨，我们还是出去）。por más que / por mucho que 同理。
⑦独立句愿望、祈使¡Que tengas suerte!↳祝你好运！省略主句（deseo / espero / ojalá），单用 que + 虚拟式构成独立祝愿句，句首常有 ¡，书面可加感叹号。同类型：¡Que te vaya bien!（一切顺利）、¡Que descanses!（好好休息）、¡Que aproveche!（多吃点）。注意此处 que 不是关系代词，而是引出愿望的连词。
B2虚拟式现在完成时Pretérito perfecto de subjuntivohaya / hayas / haya / hayamos / hayáis / hayan + p.p. 例：haya hablado, hayas visto①主句现在/将来/命令，从句动作已完成Espero que hayas terminado el informe.↳我希望你已经把报告写完了。主句是现在时 espero，触发虚拟式；从句用 haya + p.p.（hayas terminado）表示“到说话这一刻已经完成”。与 B1 的 Espero que termines（希望你去完成）相比，这里说的是完成结果，且说话人不知道是否真的完成。
②将来某一时点之前完成Cuando hayas terminado, avísame.↳你完成之后告诉我。cuando 指将来仍需虚拟式；完成体 hayas terminado 强调“到那个时候动作已完成”，从而明确先后。也可说 Cuando termines，但那只是指出时点、不强调“已完成”，属省略完成义的说法，不是等义替代。
③对近期过去的怀疑、否定判断No creo que hayan llegado todavía.↳我不觉得他们已经到了。否定判断 no creo que 触发虚拟式；hayan llegado 表示动作截至现在可能已完成，但说话人不确认。改用陈述式 No creo que han llegado 只在加勒比等部分地区口语中可见，标准语法仍要求虚拟式。
④情感/评价，针对已完成的事Me alegra que hayas encontrado trabajo.↳我很高兴你找到了工作。情感触发虚拟式；hayas encontrado 表明“找到工作”是已发生的结果。若改成 Me alegra que encuentres trabajo，情感就转为对“将来能找到”的期待，且完成义丢失——不是语义“完全不同”，而是视角改变。
⑤愿望：ojalá（事情已发生）Ojalá hayamos acertado.↳但愿我们判断对了。ojalá 后固定虚拟式；用完成体 hayamos acertado 指“结果已经产生，只是还不知道好坏”，是对既成结果的不确定期盼。对比 Ojalá acertemos（尚未决定、盼将来做对）。
B3虚拟式过去未完成时Pretérito imperfecto de subjuntivo规则：-ar → hablara / hablase；-er/-ir → comiera / comiese, viviera / viviese（两套词尾同义） 不规则：fuera/fuese, tuviera/tuviese, pudiera/pudiese, supiera/supiese, hiciera/hiciese, dijera/dijese, viniera/viniese, pusiera/pusiese①主句为过去时，从句表愿望、要求、怀疑Quería que vinieras a la fiesta.↳我当时希望你来参加聚会。主句用过去时（quería），从句随之用过去未完成虚拟（vinieras），表示“在当时那个时间点，这个愿望还没实现”。-ra 在这里不表示“过去的过去”，只是与过去主句呼应。同类主句：esperaba / pedía / dudaba / quería。
②第二类条件句：现在或未来非现实假设Si tuviera tiempo, viajaría más.↳要是我有时间，我会多旅行。事实是“现在没有时间”，因此 si 从句用过去未完成虚拟 tuviera，主句用简单条件式 viajaría（不是虚拟式）。这是与现在事实相反的假设，不能换成 si tengo tiempo（那表示真有可能）。
③愿望：ojalá（可能性低）Ojalá lloviera mañana.↳但愿明天下雨。ojalá + 过去未完成虚拟，表示说话人认为实现可能性很低（明天下雨的希望不大），带一点无奈。对比 Ojalá llueva mañana 语气更乐观、更中性。
④委婉、礼貌Quisiera hacerle una pregunta.↳我想向您请教一个问题。quisiera 是 querer 的过去未完成虚拟，用作委婉的客套形式，比 quiero 更含蓄、更有距离感；同类 pudiera / debiera / hubiera querido。对长辈、客户、面试场合常用。
⑤como si + 虚拟过去未完成（与现在事实相反）Habla como si fuera el jefe.↳他说话的口气像是老板。como si 后不能用陈述式；与现在事实相反用过去未完成虚拟（fuera 是 ser），意为“他其实不是老板”。这里的过去虚拟在语义上是“现在非现实”，不是过去时。
⑥主句过去、先行词不确定的关系从句Buscaba a alguien que hablara inglés.↳我当时在找一个会说英语的人。主句为过去时，且先行词 alguien 不确定、可能根本不存在，关系从句用虚拟式 hablara。若人已确定则用陈述式：Buscaba a Juan, que hablaba inglés.（我在找胡安，他会英语）。同类先行词：un libro que…, nada que…, alguien que…

②第三类条件句：过去反事实Si hubiera sabido la verdad, habría venido.↳我要是当时知道真相，就来了。与过去事实相反（当时并不知道，因此没来）：si 从句用 hubiera + p.p.，主句用条件完成式 habría + p.p.。拉丁美洲口语常用 Si hubiera sabido… hubiera venido（两个都用 -ra 形式），书面标准仍写 habría venido。
③未实现的愿望、遗憾：ojaláOjalá hubiera aceptado la oferta.↳真希望我当时接受了那个提议。ojalá + 过去完成虚拟，针对已经无法更改的过去选择表达遗憾（其实当时拒绝了）。对比 Ojalá acepte（盼将来接受）、Ojalá aceptara（对现在/将来低可能性期盼）。
④como si + 虚拟过去完成（与过去事实相反）Habló como si hubiera estado allí.↳他说得好像自己当时在场。主句是过去时 habló，como si 后用过完成虚拟 hubiera estado，表示“他当时其实不在场”（事先到过、已离开）。若改用 estuviera，只表示“在场”与主句动作同时，无法表达“事先已完成”，也容易被读成与现在事实相反。
⑤情感、遗憾：针对过去已发生/未实现的事Lamento que no hubieras podido venir.↳我很遗憾你当时没能来。lamento que 触发虚拟式；hubieras podido 指明“过去那次没能来”。若事情刚过去不久，也常用现在完成虚拟 Lamento que no hayas podido venir；两者都指已过去的事，只是时间视角不同。
B5虚拟式将来未完成时Futuro simple de subjuntivohablare, comiere, viviere 不规则：fuere, hiciere, dijere, tuviere, pudiere, quisiere, viniere, supiere, pusiere 现代罕用①法律、公文、规章El que infringiere la ley será sancionado.↳凡违反法律者将受处罚。法律条文对“假设将来发生的违法行为”固定用 -re 形式（infringiere 是 infringir），主句用将来时。现代文本一般改写为 El que infrinja la ley（B1）。
②古旧、文学的条件从句Si alguien viniere, avísame.↳若有人来，请告诉我。古旧/正式条件句用将来虚拟 viniere（venir）；现代规范说法是 Si alguien viene, avísame.（陈述式现在时），虚拟式不再出现在真实条件句的 si 从句里。
③谚语、固定表达Donde fueres, haz lo que vieres.↳入乡随俗。fueres 是 ir 的将来虚拟，vieres 是 ver 的将来虚拟。谚语固定沿用古体形式，不能改成现代时态，否则失去谚语的原貌。
④古体时间、让步从句Cuando llegare el momento, lo sabrás.↳时机到来时你自会知道。古体 cuando 从句用将来虚拟 llegare（llegar）；现代说法 Cuando llegue el momento, lo sabrás（B1）。多见于古典文学、演讲、法律文本。
⑤固定表达：sea lo que fuereSea lo que fuere, no cambiaré de idea.↳不管怎样，我都不会改变主意。fuere 是 ser 的将来虚拟，sea lo que fuere 为固定短语，意为“无论如何、不管是什么”。现代等义说法是 sea lo que sea（用 B1 虚拟式）。
B6虚拟式将来完成时Futuro compuesto de subjuntivohubiere / hubieres / hubiere / hubiéremos / hubiereis / hubieren + p.p. 例：hubiere visto, hubieres terminado 现代罕用①法律、公文：假设将来某时已经发生Si alguien hubiere visto algo sospechoso, que lo comunique a la policía.↳若有人看到可疑情况，请通知警方。正式法律条件句用 hubiere + p.p.（hubiere visto），假设“到那时已经看见”。现代说法 Si alguien ha visto algo sospechoso…：si 从句用陈述式，不能写成 haya visto。
②正式条件、时间从句：到某时已经完成Una vez que hubiere sido aprobada la ley, entrará en vigor.↳法律一经通过，即生效。una vez que 后用过完成虚拟被动 hubiere sido aprobada，表示“到通过那一刻已完成”。现代写法：Una vez que haya sido aprobada（B2）。
③古旧、文学表达：将来之前已完成Cuando hubieres leído el documento, firmarás.↳你读完文件之后签字。古旧书面语用 hubieres leído（tú 形式），强调“读完”先于“签字”。现代说法 Cuando hayas leído el documento, firmarás。
④假设将来某时之前完成Si para entonces hubiere terminado el trabajo, te lo enviaré.↳如果到那时我已经完成了工作，我会发给你。正式书面条件句，hubiere terminado 指“到那时之前完成”。现代说法 Si para entonces he terminado el trabajo…（陈述式现在完成）；si 从句不能用 haya terminado。
⑤法律公文：凡已经实施某行为者El que hubiere cometido el delito será juzgado.↳凡已经实施犯罪者将受审判。法律文本用 hubiere cometido 指“行为已经实施完毕”，与 B5 的 infringiere（行为尚未发生）形成对照。现代通常改为 El que haya cometido el delito（B2）。

①
愿望、请求、建议、命令

↳我希望你早点来。
esperar que 是最典型的虚拟式触发结构；vengas 指尚未发生、只存在于说话人愿望中的动作。若改用陈述式 vendrás，就把“来”当成已确定的事实预告，语气从愿望变成断言。同类动词：querer / pedir / rogar / sugerir / aconsejar / mandar que。
②
情感、评价

↳我很高兴你在这儿。

④

para que / a fin de que 引出的是“目的”，本身即要求虚拟式；又因主句主语是“我”、从句主语是“你”，不能用 para + 不定式（para saberlo 只在同主语时用）。sepas 是 saber 的虚拟式。
⑤
时间从句指将来未发生

↳你到了就告诉我。
cuando 引导的从句指将来、尚未发生且不确定的事件时用虚拟式（llegues 是 llegar）。若指习惯或已发生的事则用陈述式：Cuando llega, siempre avisa.（他每次到都会说一声）。同类连词：en cuanto, mientras, hasta que, antes de que, después de que, tan pronto como。

↳祝你好运！

Habló como si hubiera estado allí.
↳他说得好像自己当时在场。
主句是过去时 habló，como si 后用过完成虚拟 hubiera estado，表示“他当时其实不在场”（事先到过、已离开）。若改用 estuviera，只表示“在场”与主句动作同时，无法表达“事先已完成”，也容易被读成与现在事实相反。
⑤
情感、遗憾：针对过去已发生/未实现的事
Lamento que no hubieras podido venir.
↳我很遗憾你当时没能来。
lamento que 触发虚拟式；hubieras podido 指明“过去那次没能来”。若事情刚过去不久，也常用现在完成虚拟 Lamento que no hayas podido venir；两者都指已过去的事，只是时间视角不同。
B5虚拟式将来未完成时 · Futuro simple de subjuntivo
hablare, comiere, viviere 不规则：fuere, hiciere, dijere, tuviere, pudiere, quisiere, viniere, supiere, pusiere 现代罕用
①
法律、公文、规章
El que infringiere la ley será sancionado.
↳凡违反法律者将受处罚。
法律条文对“假设将来发生的违法行为”固定用 -re 形式（infringiere 是 infringir），主句用将来时。现代文本一般改写为 El que infrinja la ley（B1）。
②
古旧、文学的条件从句
Si alguien viniere, avísame.
↳若有人来，请告诉我。
古旧/正式条件句用将来虚拟 viniere（venir）；现代规范说法是 Si alguien viene, avísame.（陈述式现在时），虚拟式不再出现在真实条件句的 si 从句里。
③
谚语、固定表达
Donde fueres, haz lo que vieres.
↳入乡随俗。
fueres 是 ir 的将来虚拟，vieres 是 ver 的将来虚拟。谚语固定沿用古体形式，不能改成现代时态，否则失去谚语的原貌。
④
古体时间、让步从句
Cuando llegare el momento, lo sabrás.
↳时机到来时你自会知道。
古体 cuando 从句用将来虚拟 llegare（llegar）；现代说法 Cuando llegue el momento, lo sabrás（B1）。多见于古典文学、演讲、法律文本。
⑤
固定表达：sea lo que fuere
Sea lo que fuere, no cambiaré de idea.
↳不管怎样，我都不会改变主意。
fuere 是 ser 的将来虚拟，sea lo que fuere 为固定短语，意为“无论如何、不管是什么”。现代等义说法是 sea lo que sea（用 B1 虚拟式）。
B6虚拟式将来完成时 · Futuro compuesto de subjuntivo
hubiere / hubieres / hubiere / hubiéremos / hubiereis / hubieren + p.p. 例：hubiere visto, hubieres terminado 现代罕用
①
法律、公文：假设将来某时已经发生
Si alguien hubiere visto algo sospechoso, que lo comunique a la policía.
↳若有人看到可疑情况，请通知警方。
正式法律条件句用 hubiere + p.p.（hubiere visto），假设“到那时已经看见”。现代说法 Si alguien ha visto algo sospechoso…：si 从句用陈述式，不能写成 haya visto。
②
正式条件、时间从句：到某时已经完成
Una vez que hubiere sido aprobada la ley, entrará en vigor.
↳法律一经通过，即生效。
una vez que 后用过完成虚拟被动 hubiere sido aprobada，表示“到通过那一刻已完成”。现代写法：Una vez que haya sido aprobada（B2）。
③
古旧、文学表达：将来之前已完成
Cuando hubieres leído el documento, firmarás.
↳你读完文件之后签字。
古旧书面语用 hubieres leído（tú 形式），强调“读完”先于“签字”。现代说法 Cuando hayas leído el documento, firmarás。
④
假设将来某时之前完成
Si para entonces hubiere terminado el trabajo, te lo enviaré.
↳如果到那时我已经完成了工作，我会发给你。
正式书面条件句，hubiere terminado 指“到那时之前完成”。现代说法 Si para entonces he terminado el trabajo…（陈述式现在完成）；si 从句不能用 haya terminado。
⑤
法律公文：凡已经实施某行为者
El que hubiere cometido el delito será juzgado.
↳凡已经实施犯罪者将受审判。
法律文本用 hubiere cometido 指“行为已经实施完毕”，与 B5 的 infringiere（行为尚未发生）形成对照。现代通常改为 El que haya cometido el delito（B2）。

B5 / B6 为古体将来虚拟，只作认读，现代书面语已改用 B1 / B2。
